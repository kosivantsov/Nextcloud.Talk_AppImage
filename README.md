# Nextcloud Talk AppImage

This repository automatically tracks the official [Nextcloud Talk Desktop](https://github.com/nextcloud/talk-desktop) releases and packages them as AppImages.

## Installation via AppMan (AM)

If you use [AM](https://github.com/ivan-hc/AM), you can install and keep this AppImage updated by running:

```bash
am -e https://github.com/kosivantsov/Nextcloud.Talk_AppImage nextcloud-talk
```
